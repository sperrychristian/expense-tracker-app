# Expense Tracker — Stylesheets

Every `StyleSheet.create` block in the `expense-tracker-demo` app, with the file it belongs in. Copy/paste these into the bottom of the matching file so you can focus on the React code instead of retyping styles.

Paths are relative to the project root (the folder containing `package.json`).

Each snippet is the style block only. Make sure the file also has the imports listed above it.

## constants/styles.js

Start here. This is the whole file, not just a style block, the color palette every other file imports.

```js

  colors: {
```
